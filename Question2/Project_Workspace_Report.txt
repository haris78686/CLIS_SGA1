The umask command displays the default permission mask used while creating new files and directories. The current umask value ensures that newly created files are not writable by unauthorized users.

Permissions were modified to improve security. Only the owner has full access, group members have read access, and other users have no permissions.

======================================================
6. How Permissions Protect Project Data
======================================================

Linux permissions restrict unauthorized access to project files. By assigning only the required permissions, confidential project information remains protected while still allowing controlled access to authorized users. This follows the principle of least privilege and improves overall system security.
